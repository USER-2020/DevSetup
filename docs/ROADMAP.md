# Roadmap

1. Add a local SQLite persistence adapter for scans, plans, jobs, logs, profiles, and cached version catalogs.
2. Integrate official Node, PHP, Composer, and MySQL version metadata with cache freshness indicators.
3. Add version managers (fnm/Volta), project profile activation, import/export, and safe project inspection.
4. Add MySQL service discovery/control and post-install verification.
5. Add explicit cancellation, durable recovery, signed download verification, auto-updates, and native end-to-end CI.
